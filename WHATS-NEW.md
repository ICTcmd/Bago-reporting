## 🌟 NEW FEATURE: Community Dashboard

**Like Facebook, but for incident reports!**

### What Is It?
A public feed where **everyone** can see what incidents have been reported in Bago City. Stay informed, see what's happening in your community!

### Why It's Great:
1. **Transparency** — See what DRRMO is working on
2. **Awareness** — Know what's happening in your area
3. **Trust** — Watch reports get resolved
4. **Participation** — Feel encouraged to report issues

### Features:
- 📊 **Live Stats** — Total reports, active cases, resolved
- 🎯 **Smart Filters** — Filter by type (flood, fire, etc.) or status
- 🔒 **Privacy Protected** — No personal info shown
- 📱 **Mobile Friendly** — Works great on phones
- 🎨 **Beautiful Design** — Color-coded categories, status badges

## 🔐 Privacy Protection

### ✅ What's Shown:
- Title (e.g., "Fallen tree blocking road")
- Category (🌊 Flood, 🔥 Fire, etc.)
- Barangay (general area)
- Status (Submitted → In Progress → Resolved)
- Reference number
- Date/time

### ❌ What's Hidden:
- Exact address (privacy!)
- Reporter name (private)
- Phone number (private)
- Photos (staff-only)
- Description (may have personal info)

**Privacy notice shown on every report!**
